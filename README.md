# ИЗЛК — управление договорами и производством

Веб-приложение для договоров, контрагентов, проектов, задач, площадок, монтажных отчётов, документов и исполнительной документации.

## Что уже работает

- договоры: создание вручную, редактирование, поиск, карточка, дополнительные соглашения и сметы;
- контрагенты: создание из отдельного раздела и прямо при создании договора, поиск по названию, ИНН, телефону и почте;
- загрузка и разбор договоров из Word, Excel, PDF с текстовым слоем, TXT и CSV;
- очередь импорта из общей папки с защитой от одинаковых файлов по SHA-256;
- проекты: этапы КМ/КЖ/АР, сроки, прогресс и подсказка очереди;
- задачи: исполнитель, срок, приоритет, статус, договор, редактирование и комментарии;
- площадки: статус, обязательная причина остановки, монтаж КЖ/КМ, фото, техника и материалы;
- исполнительная документация: контроль комплектности, категории и реальные прикреплённые файлы;
- общий каталог документов с поиском, фильтрами и скачиванием полного комплекта договора;
- роли администратора, менеджера и наблюдателя;
- управление сотрудниками и паролями в разделе «Настройки»;
- журнал значимых действий и резервное копирование файлов и базы.

## Быстрый запуск на этом компьютере

Для обычного запуска дважды щёлкните файл **ЗАПУСТИТЬ ИЗЛК.cmd** в папке `C:\Users\Илья\Desktop\проект`. Окно запуска нужно оставить открытым на время работы.

Ручной запуск для разработки:

```powershell
npm.cmd install
npx.cmd prisma migrate deploy
npm.cmd run dev
```

Открыть: [http://localhost:3000](http://localhost:3000)

Для показа используются демонстрационные учётные записи из базы. Перед реальной работой смените их пароли в разделе «Настройки» и создайте отдельную учётную запись каждому сотруднику.

## Рабочая сборка

```powershell
npm.cmd run build
npm.cmd run start
```

## Резервные копии

```powershell
npm.cmd run backup:files
npm.cmd run backup:database
```

Копии сохраняются в папку `backups`. Docker для резервного копирования не требуется. Архивы из этой папки нужно дополнительно переносить на другой физический диск или в защищённое облачное хранилище.

## Автоматический импорт из папки

В `.env` задаются:

```env
INBOX_PATH="C:\\IZLK\\Входящие договоры"
INBOX_SCAN_TOKEN="длинный-случайный-токен"
```

Проверить папку можно кнопкой в разделе «Очередь импорта». Для автоматической проверки Планировщик заданий Windows должен периодически отправлять POST-запрос на `/api/inbox/scan` с заголовком `Authorization: Bearer <INBOX_SCAN_TOKEN>`.

Одинаковый файл повторно в очередь не добавляется. Это штатная защита от дублей, а не ошибка.

## Важные ограничения текущей версии

- бухгалтерия и просрочки оплаты остаются в 1С;
- обмен с базой 1С потребует отдельно согласованного API или регламента выгрузки;
- фотографии и сканы без текстового слоя пока не распознаются через OCR;
- состав управленческих отчётов ещё должен определить руководитель.

Подробная инструкция перед первым рабочим днём находится в [START-COMPANY.md](START-COMPANY.md).
