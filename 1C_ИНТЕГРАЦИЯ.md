# Обмен ИЗЛК ↔ 1С

Система подготовлена к безопасному обмену через HTTPS API. Это безопаснее прямого доступа к базе 1С: структура базы и права остаются под контролем IT заказчика.

## Что нужно от IT заказчика

1. Сгенерировать отдельный длинный токен и записать его на сервере в `.env.production`:

   `ONE_C_API_TOKEN="..."`

2. Перезапустить приложение: `docker compose up -d`.
3. В 1С создать регламентное задание, которое раз в 15–60 минут получает JSON по адресу:

   `GET https://<домен>/api/integrations/1c/contracts`

   с заголовком `Authorization: Bearer <токен>`.

## Какие данные отдаёт API

- реквизиты договора, заказчик, менеджер, сумма и валюта;
- рабочая стадия и дедлайн;
- очереди КМ / КЖ / АР;
- сумма выставленных, оплаченных, ожидаемых и просроченных счетов.

Эндпоинт закрыт токеном: без него данные не выдаются. На первом шаге это обмен **из ИЗЛК в 1С**. Обратный обмен оплатами из 1С лучше подключать вторым этапом после согласования полей и ответственного за данные.
